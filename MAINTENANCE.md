# whatiwatch — обслуживание и уход за сайтом

Сайт: https://whatiwatch-green.vercel.app
Репозиторий: https://github.com/gumkaboy/whatiwatch (ветка `main`)

## Работает ли сайт независимо от вашего компьютера?

**Да, полностью.** С момента деплоя на Vercel + Turso сайт не зависит от того,
включён ли ваш компьютер, запущен ли `npm run dev`, активен ли VPN и т.д.
Всё крутится в облаке 24/7. Единственное, для чего вам может понадобиться
локальная машина — это дальнейшая разработка (правки кода) и работа со мной.

## Как вообще происходят изменения на сайте

1. Код правится локально (Claude Code делает это в вашей папке проекта).
2. Изменения коммитятся и пушатся в GitHub (`git push`).
3. Vercel подключён к репозиторию и **автоматически** запускает новую сборку
   и деплой при каждом пуше в `main`. Обычно занимает 30–90 секунд.
4. Отдельно "редактировать сайт напрямую" нельзя и не нужно — публичный сайт
   это просто задеплоенная копия репозитория.

## Сервисы, от которых зависит сайт — что НЕ трогать

### Vercel (хостинг)
- Не удалять проект `whatiwatch`.
- Не отключать интеграцию с GitHub (Settings → Git) — иначе пропадёт
  автодеплой при пуше.
- Не удалять/менять переменные окружения (Settings → Environment Variables):
  `DATABASE_URL`, `DATABASE_AUTH_TOKEN`, `AUTH_SECRET`,
  `TMDB_API_READ_ACCESS_TOKEN`, `OMDB_API_KEY`, `KINOPOISK_API_KEY` —
  без любой из них сайт сразу перестанет работать (регистрация, вход,
  рейтинги и т.д.).
- Следить за лимитами бесплатного тарифа Hobby (Overview → Usage): трафик
  (Fast Data Transfer), число запросов (Edge Requests). При реальной
  посещаемости может понадобиться платный план Pro.

### GitHub
- Не удалять репозиторий `gumkaboy/whatiwatch`.
- Не отзывать доступ приложения Vercel к репозиторию (Settings репозитория →
  Integrations / Installed GitHub Apps) — без него автодеплой сломается.

### Turso (база данных)
- Не удалять базу `whatiwatch` — там все аккаунты пользователей, история
  просмотров, комментарии, оценки. Восстановить неоткуда, бэкапов пока нет.
- Не отзывать/не удалять auth-токен без замены значения в Vercel
  (`DATABASE_AUTH_TOKEN`) — иначе сайт потеряет доступ к базе.
- Периодически заглядывать в дашборд Turso — смотреть, не приближаетесь ли
  к лимитам бесплатного тарифа по мере роста числа пользователей.

### Сторонние API-ключи (TMDb, OMDb, Кинопоиск)
- Не перевыпускать/не отзывать ключи без одновременного обновления
  значения в Vercel — иначе соответствующая функция (поиск сериалов,
  рейтинг IMDb, рейтинг Кинопоиска) отвалится.
- **OMDb**: бесплатно 1000 запросов/день — при реальном трафике может
  не хватать, тогда рейтинг IMDb будет иногда пропадать.
- **Кинопоиск**: бесплатно всего 500 запросов/день — мы уже сегодня
  вычерпали этот лимит просто тестированием вдвоём. При публичном
  использовании рейтинг Кинопоиска будет пропадать часто — это ожидаемо
  (сайт не ломается, просто бейдж не показывается), либо нужно переходить
  на платный тариф этого API.
- **TMDb** — обычно самый щедрый лимит, самый надёжный из трёх.

## Про мой доступ к сайту

Я не сохраняю доступ между разными сессиями/диалогами — токен Vercel,
который вы дали в этом разговоре, работает только пока идёт этот диалог.
В новой сессии, если понадобится моя помощь с продакшеном (посмотреть логи,
поправить настройки), нужно будет заново создать/прислать токен
([vercel.com/account/tokens](https://vercel.com/account/tokens)).

Рекомендация по безопасности: токен, который вы создали, даёт полный доступ
ко всему вашему аккаунту Vercel и сейчас без срока действия. Стоит либо
отозвать его сейчас (Tokens → та строка → Revoke), раз срочной надобности
больше нет, либо в будущем сразу ставить разумный срок истечения
(30 дней и т.п.), когда будете создавать новый.

## Если сайт "лёг" — куда смотреть в первую очередь

1. Vercel → Deployments — не упал ли последний деплой с ошибкой сборки.
2. Vercel → Logs — рантайм-ошибки (например, база недоступна).
3. Turso dashboard — не превышены ли лимиты/не заблокирована ли база.
4. Проверить, не истёк ли какой-то из API-ключей или домен (если купите
   `.ru` — не забывайте продлевать ежегодно).
